**Por que assim:**
- O Maestro na nuvem consegue **ver** o Terminal do Mac, mas não digitar nele (o Terminal é liberado só para leitura e clique).
  Também não consegue mandar mensagem para sessões locais. Por isso, cada aba recebeu um prompt uma única vez e o
  canal entre as abas e o Maestro é o **GitHub** (push e PR).
- Antes desta rodada, as 3 abas tinham feito **a mesma pesquisa na mesma pasta**, e um `git add -A` de uma aba levou o
  relatório de outra. Agora cada aba trabalha num **git worktree próprio** (cópia separada da pasta), no próprio branch,
  e é proibido usar `git add -A`.
- "Do 5 pra frente" foi lido como as **seções 5 a 9 do `CONTEXTO.md`**, do mesmo jeito que uma aba leu "contexto 6"
  como a §6 na rodada anterior.

## 3. Regras para todas as abas

- Nunca `git add -A`; adicionar só os próprios arquivos. Conventional Commits em português.
- No máximo 1 subagente por aba (3 abas = 3 subagentes, o limite do `AGENTS.md`).
- Nenhum dado real de paciente, segredo ou certificado. Norma sempre com fonte (URL + data). FATO separado de ESTIMATIVA.
- **Não fazer merge.** O merge é dos sócios, depois da revisão do Maestro.
- **Continuidade:** push a cada commit, arquivo de estado sempre atualizado (feito / falta / próximo passo / último commit)
  e, perto de 90% de uso, parar, commitar, atualizar o estado e dar push.

## 4. Como o Maestro acompanha

- **Monitor no GitHub:** a cada 60 s, o Maestro confere branches e PRs. Cada push ou PR novo das abas gera um aviso e uma revisão.
- **Olhar o Terminal:** capturas de tela das 3 abas (só leitura) para ver se travaram, se pediram algo ou se o crédito acabou.
- **Testes na nuvem:** cada branch que chega é testado com a mesma bateria do CI: lint, typecheck, testes unitários, RLS e
  segurança, contra um PostgreSQL 16 efêmero. Para a interface, o Maestro usa **Playwright**.
- **Retomadas agendadas:** hoje às 21:30 e amanhã às 9:00. Se os créditos das abas acabarem, o Maestro continua as frentes
  paradas há mais de 30 min, no próprio branch delas, a partir do arquivo de estado.
